# Докки 0.2.3

- После обновления интерфейс больше не берётся из кэша прежней версии ни на macOS, ни в Windows. Чаты и настройки сохраняются, кэш старых версий удаляется.
- Проверка обновлений начинается при открытии приложения. Новая версия, загрузка и перезапуск - одной строкой внизу левого меню: нажатие сразу скачивает или перезапускает.
- Старый интерфейс и переключение на него исключены из поставки.
- В Windows исправлены коды завершения проверок проекта и мутационного тестирования; хук плагина, который запрещает действие, теперь действительно его запрещает.
- В Windows русские имена файлов, веток и коммитов в git больше не превращаются в кракозябры.
- Мутационное тестирование в Windows находит python из venv, а поиск ссылок и переименование в TypeScript не заходят в node_modules.
- Скрипты хуков плагинов сохраняют право на запуск из GitHub; служебные .DS_Store, Thumbs.db и desktop.ini больше не выключают плагин.
- Обновление в Windows заранее проверяет права на папку программы и честно пишет об ошибке, вместо того чтобы закрыться и остаться на старой версии.

# Докки 0.2.2

- Агент проверяет свою работу: перед завершением задачи запускает проверки проекта (lint, типы, тесты), чинит найденное не больше трёх раз и честно пишет в итоге «проверено», «не проверено» или «проверки не прошли».
- Независимое ревью изменений отдельным запросом без истории диалога; режим в настройках разработки (авто, всегда, выключено).
- Проверка страниц в браузере: шаги, утверждения, ширины телефона/планшета/компьютера, ошибки консоли и сети, сравнение со скриншотом-эталоном.
- Агент понимает код: определения, ссылки, переименование и вынос функции для Python и TypeScript без правки одноимённых чужих символов; анализ влияния изменений.
- Точный контекст: агент берёт нужные фрагменты кода вместо целых файлов.
- Знания проекта: решения и соглашения сохраняются между чатами, устаревшие помечаются, ваши правки агент не перезаписывает; выгрузка в Markdown.
- Документация библиотек по версии из проекта; Context7 только с вашего подтверждения.
- Навыки подбираются под задачу автоматически, автоподбор можно выключить для любого навыка; SKILL.md из папки проекта работает только после подтверждения.
- «Откатить весь ход» в изменениях: возвращает файлы хода к состоянию до него и не трогает ваши правки, сделанные после агента.
- Поиск и чтение страниц агентом идут через сервер Докки (DeepSeek Search и Fetch): точнее выдача и чище текст страниц. Без входа и при сбое сервера - как раньше, с этого компьютера; локальные и частные адреса на сервер не уходят.
- Объективные гейты качества кода: сложность с учётом покрытия (CRAP < 10), структурные дубли, слои архитектуры и мутационное тестирование изменённых строк в изолированной копии проекта. «Не измерено» никогда не выдаётся за «прошло». Глубина по режиму рассуждения или вручную в настройках разработки.
- Агент работает по стадиям Make It Work → Make It Right → Practice: красный тест засчитывается, только если упал на проверке, а не на импорте; после двух провалов одной проверки на разных версиях кода агент обязан пересмотреть исходное допущение. Решения агента сохраняются и переживают сжатие контекста.
- Карточка «Качество» в правой панели: статусы гейтов с числами, переход к строке, «Принять» и «Исправить» для находок, журнал решений агента, подсветка долга на карте проекта.
- Политика слоёв проекта в настройках: агент только предлагает разметку, применяете её вы.
- Безопасный git: агент добавляет в коммит только свои файлы, подготовленное вами в индексе остаётся нетронутым, «git add .» не выполняется, повтор коммита после обрыва не создаёт второй. Очистка старых рабочих копий удаляет только чистые копии Докки без своих коммитов.
- Два хода агента не правят одну папку одновременно.
- Новый навык «Инженерное качество (UB-mode principles)».
- Плагины Claude Code и Codex с GitHub: установка по ссылке или из каталога 50 популярных бесплатных открытых плагинов. Докки скачивает только с github.com, закрепляет плагин на коммит и сверяет каждый файл; навыки и команды плагина подключаются как обычные навыки или словом /плагин:команда в начале сообщения. Хуки и MCP-серверы плагина работают только после вашего разрешения для конкретной версии; плагин можно выключить или удалить, у каждого аккаунта свои плагины. Если файлы плагина изменились на диске, его хуки и MCP не запускаются, а любой запуск скрипта плагина агентом Докки спрашивает у вас даже в режиме «Разрешить всё». Хуки плагинов PreToolUse, PostToolUse и Stop работают как в Claude Code: могут запретить действие агента, оставить замечание к результату или попросить доработать перед завершением, но не могут разрешить то, что запрещает Докки. Плагины из папки большого репозитория ставятся быстрее: Докки качает только их файлы.

- Безопасность агента: переключение ветки и «вернуть файл из git» больше не стирают ваши незакоммиченные правки - имя ветки не принимается за путь или ключ, а возврат файла записывается как обычная правка, которую можно откатить. Агент не правит файлы внутри .git, а git, который запускает Докки, не исполняет команды из чужого core.fsmonitor.
- Агент не может завершить процессы самой Докки или все процессы разом; папка данных Докки закрыта для агента при любом регистре букв в пути.
- Автоматизация, прерванная закрытием приложения, больше не выпадает из расписания навсегда.
- Сжатие длинного чата не падает, когда последний шаг агента вернул большие результаты: они заменяются пометкой, чат можно продолжить.
- Windows: ключ сессии окна не уходит в запросы из встроенной страницы сайта, а запросы и WebSocket с чужого адреса отклоняются.

# Докки 0.2.1

- Агент больше не зависает на подтверждении: карточка «Разрешить» появляется и для задач из очереди, даже если окно подключилось к ходу позже.
- Список MCP-инструментов без настроенных серверов не требует подтверждения.
- Голосовой ввод как на сайте Докки: «+» во время записи становится отменой, таймер записи, кнопка отправки распознаёт и сразу отправляет.
- Очередь на подложке с размытием и не накладывается на текст ленты; кнопки строки появляются при наведении.
- Везде имя «Докки»; новые проекты по умолчанию в «Документы/Dokky Projects» (старая папка остаётся, если уже есть).
- Автообновление на macOS и Windows: раздел «Обновления» в настройках, проверка при запуске и раз в 6 часов, загрузка в фоне с проверкой SHA-256, перезапуск в новую версию одной кнопкой. Если новая версия не стартует, возвращается прежняя.
- «Изменить сообщение» в разработке как в Claude Code: чат откатывается к этому сообщению, всё после него удаляется, текст и вложения возвращаются в поле ввода. Если агент менял файлы, их можно оставить или откатить вместе с чатом.
- Подписка и оплата как на сайте: ползунок вкладок и перелистывание карточек планов. Вместо «Оплата пока недоступна» - «Включено в ваш доступ» для безлимита и понятная причина, если оплата правда недоступна.
- Шрифт кода выбирается из установленных моноширинных шрифтов, предпросмотр раскрашен. По умолчанию системный (SF Mono / Menlo на Mac, Cascadia / Consolas на Windows).
- Отправка сообщения: выбор «Enter» или «⌘Enter / Ctrl+Enter» вместо тумблера.
- Меню, настройки и кнопки больше не выделяются как текст.
- На Windows команды агента и служебные процессы запускаются без окон консоли и PowerShell.
- Подтверждения доходят надёжнее: карточка появляется сразу по событию сервера, есть страховочная проверка, ответ с телефона закрывает карточку в окне.
- Чаты компьютера сразу видны на сайте и в телефоне после входа (если доступ не выключали), с понятным именем компьютера вроде «MacBook Pro Иван» или «ПК Иван».
- Навигатор сообщений справа работает и когда лента прокручена до конца.
- Кнопка копирования показывает галочку «Скопировано». Подсветка кода в светлой теме читается лучше.

# Докки 0.2.0

Первый публичный релиз. Докки - настольное приложение для Windows и macOS: чат с серверным
AI Докки и локальная среда разработки, где агент работает прямо с вашими проектами.

## Что это

В одном окне два режима. Обычные чаты Докки: ответы потоком, поиск в сети, источники,
вложения и библиотека всего, что вы делали. И «Докки Code»: проекты на вашем диске, в
которых агент читает и правит файлы, запускает команды и тесты, работает с Git и браузером.

Модели крутятся на сервере Докки. Приложение входит через ваш аккаунт Докки, свои серверы
моделей, ручной ввод ключей и локальные LLM не поддерживаются.

## Что умеет

- Чаты с потоковыми ответами, веб-поиском, источниками и вложениями.
- Локальные проекты со своими чатами разработки и собственным агентным циклом, без жёсткого
  лимита шагов.
- Чтение, поиск и правка файлов, запуск команд и проверок, работа с Git, встроенный браузер.
- Режим планирования: агент сначала составляет план, ничего не записывая, потом вы
  запускаете сохранённый план.
- Контроль над агентом: разрешения на действия, остановка задачи, журнал, просмотр изменений
  и откат.
- Правила проекта из `AGENTS.md`, MCP-серверы, навыки, память проекта и сжатие длинной
  истории.
- Computer Use: агент может управлять компьютером, но только если вы включили это отдельно,
  и каждое действие подтверждается.
- Родной вид на каждой системе: на macOS окно с эффектом Liquid Glass и нативным WKWebView,
  на Windows Qt WebEngine.

## Установка на Windows

Скачайте `Dokky-0.2.0-Windows-x64-Setup.exe` и запустите. По умолчанию Докки ставится в
`%LOCALAPPDATA%\Programs\Dokky` только для вас, права администратора не нужны. Если выбрать
папку в Program Files, установщик спросит права и поставит для всех пользователей.

Не хотите ставить - берите `Dokky-0.2.0-Windows-x64-portable.zip`: распакуйте куда угодно и
запускайте `Dokky.exe`. Чаты и настройки переносная версия хранит рядом с собой, в `.koddi-data`.

Файлы пока не подписаны, поэтому SmartScreen при первом запуске покажет предупреждение.
Нажмите «Подробнее» -> «Выполнить в любом случае». Контрольные суммы в `SHA256SUMS-windows.txt`.

Удалить можно как обычно: Параметры -> Приложения. Чаты и настройки при этом остаются,
если не поставить галочку «Удалить также чаты и настройки».

## Установка на macOS

Образы лежат в файлах релиза: `Dokky-0.2.0-macOS-arm64.dmg` для Apple Silicon и
`Dokky-0.2.0-macOS-x86_64.dmg` для Intel. Контрольные суммы в `SHA256SUMS-macos.txt`.

Откройте образ и перетащите Докки в «Программы».

Приложение подписано ad-hoc, без Developer ID и нотаризации, поэтому macOS при первом
запуске его заблокирует. Откройте Системные настройки -> Конфиденциальность и безопасность
и нажмите «Всё равно открыть». Микрофон, запись экрана и управление компьютером система
спрашивает отдельно.

Computer Use на macOS требует версию 14 и выше.

## Данные и безопасность

Настройки, история разработки и токен хранятся вне папок проектов: на Windows в
`%LOCALAPPDATA%\Koddi`, на macOS в `~/Library/Application Support/Koddi`. Токен лежит в
зашифрованном виде. Бэкенд слушает только loopback, а доступ агента ограничен выбранными
вами рабочими папками. О проблемах с безопасностью смотрите [SECURITY.md](SECURITY.md).
