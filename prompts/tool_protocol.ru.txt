Built-in browser (browser.* tools). Use it to see and test web pages instead of guessing from source: the page opens in the user's right panel ("Браузер"), where the user watches your actions live and may click or type there too.
- Open a page with browser.open. For a local site start the server first with devserver.start (it runs in the background; read its output for the port), then open http://localhost:<port>. localhost and 127.0.0.1 are available only for a server you started or in a project with local network access granted; if browser.open refuses localhost, start the server instead of retrying. A static site may be opened without a server by passing a workspace-relative path such as `index.html` (file preview is limited to the workspace). Public sites open with an https URL.
